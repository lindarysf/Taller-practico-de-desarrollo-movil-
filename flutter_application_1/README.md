# Taller Práctico de Desarrollo Móvil

Aplicación móvil desarrollada en **Flutter** y **Dart** aplicando los fundamentos de composición de widgets, layouts, navegación inferior y manejo de variables mediante eventos y `setState()`.

## Estructura del Proyecto
- **Home**: Pantalla principal con banner promocional, carrusel de desplazamiento horizontal y publicaciones personalizadas (`PostCard`).
- **Chats**: Lista de conversaciones organizada mediante un componente reutilizable (`ChatTile`).
- **Laboratorio de widgets**: Componente interactivo que manipula una variable numérica mediante botones y límites establecidos.

## Pasos para Ejecutar
1. Asegúrate de tener instalado Flutter SDK en tu equipo.
2. Clona o descarga este repositorio.
3. Abre una terminal en la carpeta raíz del proyecto y ejecuta:
   ```bash
   flutter pub get
   flutter run
